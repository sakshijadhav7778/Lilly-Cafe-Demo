# Lilly Cafe — Whimsical Website Demo

This demo uses the Lilly Cafe photographs supplied for the concept.

## Files
- index.html
- style.css
- script.js
- assets/ (Lilly photographs)

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
Upload all files/folders to a GitHub repository, keep `index.html` in the root,
then enable Settings → Pages → Deploy from branch → main / root.

## Before showing to the client
- Replace demo menu items with Lilly's final menu.
- Confirm opening hours.
- Confirm address/phone/Instagram.
- Replace any demo wording the client wants changed.
